## API 契约（前端复用，无新后端）
- `GET /web/line/list` → `data[]`，每条 `realtimeData` 是 JSON 字符串（含 occupancyRate/occupancy=数量/efficiency）。
- `GET /web/system-config` → 8 条配置（含 4 条 occupancy.*）。
