# 20-工控机现场探查清单

> 目标：在已部署海康视觉平台资源管理器（hik-java.exe + PostgreSQL + 看门狗）的 Windows 工控机上，部署我们自己的工业数据采集软件前，摸清现场环境，决定海康数据抓取路线：A1 代理拦截 MES 上传，或 A2 直读海康 PG 库，或 A1+A2 双保险。
>
> 探查顺序：先跑自动化脚本拿硬数据，再按人工清单补全脚本拿不到的画面信息、业务信息和现场网络情况；最后用"拍板决策表"给出推荐方案。

## 一、自动化探查清单（脚本 probe-edge.ps1 已覆盖）

下表所有自动化项均由 `scripts/probe-edge.ps1` 采集，在生成的《探查报告-<机器名>-时间.md》中对应章节给出 ✅/⚠️/❌ 结论、关键原始数据和建议动作。现场无需逐项手工核对，只需在脚本跑完后重点检查⚠️/❌项并补拍对应画面。

- 机器基础信息 [脚本已覆盖]：机器名、OS 版本/构建号、CPU 型号/核数、内存总量/可用、磁盘（系统盘+数据盘总/剩）、网卡/IP/MAC、开机时长、当前用户及是否管理员。
- .NET 运行时 [脚本已覆盖]：.NET Framework 4.x 子版本、.NET Core/.NET 5+ 已安装版本清单。
- 时间同步 [脚本已覆盖]：时区、本地时间、NTP 服务器配置、w32tm 同步状态、最近一次成功同步时间。
- 防火墙状态 [脚本已覆盖]：域/专用/公网三 profile 启用情况、是否允许 ICMP、关键入站开放端口（含 5432/80/443/8080/8443/RDP 等）。
- 远程桌面 [脚本已覆盖]：RDP 注册表开关（fDenyTSConnections）、RDP 端口。
- 海康软件定位 [脚本已覆盖]：C:/D: 优先全盘搜索 `hik-java.exe`、PSM 目录、platform/manager 配置目录，列出路径、版本号、文件修改时间。
- 海康进程 [脚本已覆盖]：枚举 `hik-*`、`postgres*`、`java*`、看门狗类进程，记录 PID、CPU、工作集内存、启动时间、完整命令行。
- 海康监听端口 [脚本已覆盖]：`netstat` 全量 LISTENING 端口，重点标记 80/443/5432/8080/8443 及 java 进程占用端口、对应 PID/进程名。
- 海康配置扫描 [脚本已覆盖]：安装目录下 `.properties/.yml/.yaml/.xml/.json/.conf`，按关键词 `mes/upload/gateway/dataportal/invoke/url/jdbc/postgres/password/datasource/api` grep，敏感字段只显示前 2 位+***+后 2 位。
- 海康数据库探测 [脚本已覆盖]：在海康目录或 PG 安装路径下定位 `psql.exe`，尝试用默认或配置里读到的账号连 127.0.0.1:5432，列数据库、大小、前 50 张表+行数估计、可识别业务表的最新数据时间；失败时记录"端口不通/密码错/服务未起"等原因。
- 海康日志扫描 [脚本已覆盖]：最近 24 小时日志（优先 `SourceManager.log`、文件名含 `upload/mes/gateway` 的日志），grep `mes/upload/POST/invoke/dataportal/error/exception`，给命中条数和最后 20 条样例。
- 看门狗/计划任务 [脚本已覆盖]：Windows 服务名含 `hik/psm/platform` 的项；计划任务里相关项；识别是否存在短周期（秒级/分钟级）拉起守护。
- 网络连通性 [脚本已覆盖]：TCP 到 8.8.8.8:53、默认网关、以及配置里扫到的 MES 地址/端口，记录是否连通及耗时。
- 已安装软件清单 [脚本已覆盖]：从注册表 `Uninstall` 读取 DisplayName/Version，过滤 `hik/海康/java/postgres/mysql/tdengine/redis/iis/nginx/wireshark/npcap/teamviewer/anydesk/vnc/向日葵` 等关键字。
- 资源占用快照 [脚本已覆盖]：Top10 CPU 进程、Top10 内存进程，便于判断是否还有余量跑我们的采集程序。

## 二、人工目视探查清单（脚本拿不到，必须现场补）

脚本跑完后，现场操作员按下列项目逐项看、问、拍。每一项都要留照片/录像，尽量拍到窗口标题栏和系统托盘，方便远程判断。

1. 工控机外观与硬件环境
- 怎么看：走到机柜前，看机箱铭牌、贴标、显示器桌面、键盘鼠标是否接好、是否有 U 盘锁/机箱锁、是否接 UPS。
- 看什么：设备型号、序列号、是否双机热备/主备机、机柜里是否有上位机/MES 终端/交换机/防火墙设备、网线标签、USB 口是否被封。
- 拍照：整机正面+背面接口各一张、机柜内部全景一张、网线标签近照一张。

2. 海康软件运行画面
- 怎么看：在桌面和系统托盘找海康资源管理器、PSM、平台管理客户端图标，双击打开主界面。
- 看什么：软件名称与版本号（关于/帮助菜单里）、当前在线相机数、是否有"运行中/已连接 MES/数据上传中"状态灯、有无告警红标。
- 拍照：桌面整体一张、托盘图标展开一张、海康主界面（含版本号）一张、系统状态/监控页面一张。

3. 现场网络拓扑
- 怎么看：问现场 IT/设备工程师，同时打开"网络连接"、`ipconfig` 结果对照。
- 看什么：这台工控机有几块网卡，哪块连相机内网（通常是 192.168.x/10.x 段）、哪块连厂内办公网/MES 网；是否经过隔离网闸、是否走代理上网、MES 服务器 IP/域名/端口、是否有 HTTPS 证书校验、是否要求白名单。
- 拍照：网络适配器列表一张、`ipconfig /all` 终端窗口一张、如果工程师能提供拓扑图请翻拍一张。

4. MES 上传行为确认
- 怎么看：请现场人员登录海康平台管理页面，找"系统设置/第三方对接/MES对接/数据上传/网关配置"菜单；同时观察最近 24 小时有无上传记录、失败重试。
- 看什么：MES 对接是 HTTP/HTTPS 还是 WebService/TCP 长连接、目标 URL/IP/端口、上传频率（实时/批次/人工触发）、上传字段里是否含图片/大文件、有无签名/鉴权（Token/AppKey/白名单IP）、是否支持重传。
- 拍照：MES 对接配置页一张（密码打码）、最近上传成功/失败日志页一张。

5. 数据库侧权限与业务表
- 怎么看：脚本里如果 psql 连不上，需要现场确认 PG 端口、账号、是否允许本机 Trust 登录、业务库名。
- 看什么：海康 PG 是否只监听 127.0.0.1、是否对外开放 5432、业务库命名规律（如 `hikplatform`/`sm`/`psm`）、有无明显结果表（如 `result_*`、`defect_*`、`task_*`）、是否按天分表、数据保留周期。
- 拍照：pgAdmin/Navicat 如果已安装则截一张库表结构；否则只记录脚本报告内容即可，**不要**私自尝试破解密码。

6. 安全与运维约束
- 怎么看：问现场运维/IT：这台机器是否加域、是否有 EDR/杀软（360/天擎/火绒/Symantec）、是否允许我们放一个常驻 exe/服务、开放一个新端口是否要走变更、能否重启、能否打日志、是否有远程协助通道。
- 看什么：杀软弹窗/白名单流程、是否有 U 盘管控、是否有操作审计、是否需要现场人员全程陪同、维护窗口时间段。
- 拍照：控制面板"程序和功能"里杀软/管控类项、系统时间右下角一张（用于核对时间）。

7. 现场业务节奏
- 怎么看：问产线班长/工艺：这个工位/这条线现在每天生产时长、节拍、当前是否在生产、即将到来的停线窗口是什么时候。
- 看什么：是 24h 连续生产还是白班/两班倒、是否允许在线试运行采集程序、对实时性要求（秒级/分钟级）、数据上传错误是否会触发 MES 锁线。
- 拍照：不需要拍照，文字记录在报告最后"现场沟通纪要"里即可。

## 三、拍板决策表（A1 代理拦截 vs A2 直读 PG）

| 条件（脚本+人工结果） | 推荐方案 | 说明 |
| --- | --- | --- |
| MES 上传走 HTTP/HTTPS，URL/端口明确，无双向证书/强签名，海康支持 HTTP 代理或可在本机改 hosts/配系统代理不被看门狗还原；PG 端口不开放或 psql 连不上/密码未知 | **A1 代理拦截** | 在工控机本机起一个本地正向代理或反向代理，劫持 MES 上传流量镜像/解析入库，风险低、不碰海康库。 |
| MES 上传是长连接/私有协议/有证书双向校验/上传内容不含完整业务字段（仅过账信号）；而 PG 监听本机、能拿到账号密码或 Trust 登录、业务表结构清晰、数据时效满足要求 | **A2 直读 PG** | 通过只读账号（建议新建 read-only 角色）按批次/增量拉取结果表，性能稳定，对 MES 链路零侵入。 |
| MES 配置可见但有签名/白名单，PG 也可直连但按天分表且存在补传/返工回写；客户对稳定性要求高、允许我们放两个常驻进程 | **A1+A2 双保险** | A1 拿实时过账事件/补传事件，A2 做全量对账/补数，用主键去重，可显著降低漏数风险。 |
| MES 地址扫不到、也无配置页可见，PG 端口未监听/密码未知且现场无人能提供 | **暂缓，不开工** | 脚本报告标记"红"，先请现场协调海康厂商或 IT 开放账号/配置后再进场。 |
| 杀软/EDR 严格禁止新增 exe/服务，防火墙不允许开新端口，或看门狗会定时杀掉非白名单进程 | **暂缓，走变更** | 先提变更申请加白名单，或改为离线上传方案（U 盘/网闸摆渡），不要硬上。 |

判定原则：优先选对海康现有链路侵入最小、可回滚、可快速卸载的方案；能读库就不拦流量，能拦本地代理就不动网络设备。双保险用于关键工位、不能漏数的终检/AOI 工位。

## 四、给现场操作员的运行步骤

1. 把 `scripts` 整个文件夹用 U 盘拷到工控机桌面（不要放网盘/中文路径深目录）。
2. 右键点击 `probe-edge.ps1`，选择"使用 PowerShell 运行"；如果被执行策略拦截，打开 PowerShell 执行：`Set-ExecutionPolicy -Scope CurrentUser Bypass`，再运行 `.\probe-edge.ps1`。
3. 全程鼠标不要关窗口，等脚本自动跑完（通常 3-10 分钟），窗口最后会显示"探查完成"和报告文件名。
4. 报告生成在仓库根 `reports/probe/` 文件夹里，文件名形如 `probe-report-<hostname>-<yyyyMMdd-HHmmss>.md`。
5. 按本文档"二、人工目视探查清单"逐项补拍照片（建议另建一个以机器名命名的文件夹存放照片）。
6. 把 `reports/probe/` 文件夹里最新那份 md 报告和照片文件夹一起打包成 zip，发回给开发对接人。
7. 过程中如果遇到报错，把终端窗口截图一并发回，不要自己重启海康服务或改任何配置。
8. 全程不要关闭海康资源管理器、不要拔网线、不要在生产节拍高峰期长时间占用 CPU。
