## 📐 产线物理布局

### 单条产线俯视图（南北方向）

```
                         ┌─────── 北 ───────┐
                         │                  │
   ╔════════════════════════════════════════════════╗
   ║                                                ║
   ║   ┌──────────────────────────┐  ┌──────────┐   ║
   ║   │  A1 排手模（北边）         │  │ B1 排手模 │   ║
   ║   │  📷  📷  📷               │  │ 📷 📷 📷  │   ║
   ║   │  3 个视觉相机              │  │ 3 个相机  │   ║
   ║   └──────────────────────────┘  └──────────┘   ║
   ║                                                ║
   ║   ┌──────────────────────────┐  ┌──────────┐   ║
   ║   │  A2 排手模（北偏南）        │  │ B2 排手模 │   ║
   ║   │  📷  📷  📷               │  │ 📷 📷 📷  │   ║
   ║   │  3 个视觉相机              │  │ 3 个相机  │   ║
   ║   └──────────────────────────┘  └──────────┘   ║
   ║                                                ║
   ╚════════════════════════════════════════════════╝
                         │                  │
                         └─────── 南 ───────┘

   A 面（A1+A2）：北边两排手模
   B 面（B1+B2）：南边两排手模
```

### ⚠️ 容易混淆的点

- **A 不是"北"**：A 是"北边**一组**两排"（A1 + A2）
- **B 不是"南"**：B 是"南边**一组**两排"（B1 + B2）
- **A1 不是最北**：A1 是 A 面的"靠北那排"，但 A2 在 A1 南方一些
- **B1 不是最南**：B1 是 B 面的"靠南那排"，但 B2 在 B1 北方一些

**记忆口诀**（老板说的）：
- "**南边两排**手模命名为 **B 面**"
- "**北边两排**手模命名为 **A 面**"
- "**A 面靠北那一排**叫 **A1**，**靠南那一排**叫 **A2**"
- "**B 面靠南那一排**叫 **B1**，**靠北那一排**叫 **B2**"

## 🔢 命名约定 → 数据库 / DTO 映射

| 现场说法 | DB 字段 | DTO 字段 | 取值示例 |
|---|---|---|---|
| 产线编号 | `line.line_no` | `DetectDataUploadDTO.lineNo`<br>`AlarmDTO.lineNo` | `L01` / `L02` / ... / `L10` |
| 面编号 | `line.face_no` | `DetectDataUploadDTO.faceNo`<br>`AlarmDTO.faceNo` | `A` / `B` |
| 排号（A1/A2/B1/B2） | **（暂未入 DB）** | **（暂未入 DTO）** | `A1` / `A2` / `B1` / `B2` |
| 相机编号 | `status_record.device_no` | （在状态上报里） | 待定（每个相机唯一） |
| 设备名称 | `status_record.device_name` | （V1.10 新增） | 待定 |

```sql
-- PSM defect_record 表（实际只有 line_no + face_no）
line_no  varchar(20)    -- L01
face_no  varchar(20)    -- A 或 B
```

- 还是说**视觉软件自身处理排号**，PSM 只按"面"接收？

| 排数 | 4 | 40 |
| 面数 | 2 | 20 |
| 相机数 | 12 | 120 |
| 手模数（4 排手模，每排多少个手模？） | 待查 | 待查 |

⚠️ **PM 待确认**：每排手模上有**多少个手模**？每只手模对应一只手套。30 个？50 个？100 个？

如果每排 50 个手模 → 单产线 200 个手模 → 单车间 2000 个手模 = **单车间同时在生产 2000 只手套**。

这个数字影响**数据库量级估算**（每天产生多少 defect_record）。
