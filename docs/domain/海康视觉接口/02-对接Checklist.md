# 海康视觉检验数据接口对接 Checklist

> 用于双方对接排期与验收，每一项完成后打勾并填写责任人/完成时间。

---

## 一、前期准备（双方）

- [ ] **双方接口人确认**：海康侧技术/业务接口人、英科侧技术/业务接口人、联系方式拉群
- [ ] **环境清单对齐**：开发 / 测试 / 生产三套环境的 IP、端口、访问方式确认
- [ ] **网络连通**：
  - [ ] 英科测试 `192.168.32.86:1025` 海康侧可访问
  - [ ] 英科正式 `192.168.80.33:10031` 海康侧可访问
  - [ ] 海康接口地址（待提供）英科侧可访问
  - [ ] 必要的防火墙/白名单开通
- [ ] **账号凭证**：登录账号 `HKSJSB / HKSJSB123` 在各环境可用性确认；生产环境是否需要独立账号
- [ ] **字段命名定稿**：
  - [ ] 统一 `lineGroup`（原 `lindGroup/linds` 笔误）
  - [ ] 接口 2 请求字段名确定（`lineGroup/defectGroup/faceGroup` vs `lines/defects/faces`）
  - [ ] 接口 2 响应外层结构确定（`success+data` vs `code+results`）
- [ ] **时间格式统一**：双方约定使用 ISO 8601（`YYYY-MM-DDTHH:mm:ss`）或保持 `YYYY-MM-DD HH:mm:ss`，全接口统一
- [ ] **字典对齐**：
  - [ ] 产线编码（Line）取值清单
  - [ ] 面别（Face）取值清单（A/B/Front/Back 等）
  - [ ] 缺陷类型（defectGroup）完整清单
  - [ ] 报警类型（AlarmType）、报警等级（AlarmLevel）枚举
  - [ ] 报警处理结果（AlarmResult）枚举：未处理 / 已处理 / 误报 / …
  - [ ] WorkShop 车间代码与实际工厂、组织架构的映射确认
- [ ] **URL 补全**：
  - [ ] 海康接口 1（配置查询）完整路径
  - [ ] 海康接口 2（检测数据查询）完整路径
  - [ ] 英科接口 4 完整路径（已明确同 dataportal/invoke）

## 二、海康侧开发任务

- [ ] **接口 1：配置查询** 开发完成（GET）
  - [ ] 返回 lineGroup / defectGroup / faceGroup 三个数组
  - [ ] 统一错误码与 message
- [ ] **接口 2：检测数据查询** 开发完成（POST）
  - [ ] 支持按 time / lineGroup / defectGroup / faceGroup 过滤
  - [ ] 未传过滤条件默认查全部
  - [ ] 返回 defects[] 与 removeCounts[]
  - [ ] 明确 time 整点的查询语义（小时内聚合 / 时点）
- [ ] **海康接口鉴权** 方案落地（如需要）：Token / 白名单 / 无需鉴权
- [ ] **英科登录接口调用**：
  - [ ] 登录逻辑实现，缓存 Ticket
  - [ ] Ticket 过期自动重登机制
- [ ] **报警数据推送**（接口 4）：
  - [ ] 异常发生实时触发推送（单条/批量）
  - [ ] 异常处理完成后再次推送（AlarmResult 为已处理等）
  - [ ] 失败重试机制（指数退避，重试次数/间隔约定）
  - [ ] 批量大小控制（建议 ≤ 200 条/次，待确认）
- [ ] **时间格式** 全部对齐为约定格式
- [ ] **单元/集成测试** 通过
- [ ] **接口文档**（Swagger/YApi/Postman）交付英科

## 四、联调阶段

- [ ] **测试环境连通性 PING**：双方互 ping / curl 通
- [ ] **登录联调**：海康侧成功拿到 Ticket
- [ ] **接口 1 联调**：英科调用海康配置接口，字典数据正确
- [ ] **接口 2 联调**：
  - [ ] 不带过滤条件查询
  - [ ] 带产线/缺陷/面别过滤查询
  - [ ] 无数据场景返回空数组而非 null
  - [ ] 异常参数（非法 time、不存在产线）返回规范错误
- [ ] **接口 4 联调**：
  - [ ] 单条报警上传成功
  - [ ] 批量报警上传成功
  - [ ] 异常发生 → 处理完成 两次上传，状态正确更新
  - [ ] 重复推送幂等验证
  - [ ] Ticket 过期场景重登后成功
  - [ ] 错误 Ticket 返回明确错误
- [ ] **字段取值校验**：WorkShop 枚举、AlarmResult 枚举、时间格式全部用真实数据验证
- [ ] **性能验证**：单次批量 100/500 条报警上传响应时间；每小时拉取检测数据响应时间
- [ ] **异常/重试**：网络抖动、对方服务不可用时重试和告警机制验证
- [ ] **日志**：双方都具备请求/响应日志，方便排障
