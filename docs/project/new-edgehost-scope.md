```
┌──────────────────────┐      ┌──────────────────────┐

└──────────┬───────────┘      └──────────▲───────────┘
           │ POST                       │ GET (Web UI)
           │ /client/data/*             │
           ▼                            │
┌──────────────────────────────────────────────────────┐
│                PSM (海康大屏)                          │
│   ┌────────────┐  ┌────────────┐  ┌──────────────┐    │
│   │ HTTP Server │→│ 业务服务    │→│ PostgreSQL   │    │
│   │ (REST API) │  │ (Spring)  │  │  数据库       │    │
│   └────────────┘  └────────────┘  └──────────────┘    │
│                          │                            │
│                          ▼                            │
│                   ┌──────────────┐                    │
│                   │ 英科统一网关   │                    │
│                   │ 推报警 / 登录 │                    │
│                   └──────────────┘                    │
└──────────────────────────────────────────────────────┘
```

### 新 EdgeHost 架构（PM 提议，老板决策）

```
┌──────────────────────┐      ┌──────────────────────┐
│  视觉软件              │      │  车间操作员            │
│  (现场 120 个相机)     │      │  Web 浏览器            │
└──────────┬───────────┘      └──────────▲───────────┘
           │ POST                       │ GET
           │                            │
           ▼                            │
┌──────────────────────────────────────────────────────┐
│       新 EdgeHost (我们做的)                          │
│   ┌────────────┐ ┌────────────┐ ┌────────────┐        │
│   │ HTTP接收   │ │ 视觉数据    │ │ Web UI     │        │
│   │ /client/*  │→│ 解析+存库  │←│ 大屏/查询  │        │
│   └────────────┘ └────────────┘ └────────────┘        │
│   ┌────────────┐ ┌────────────┐                       │
│   │ OPC UA     │ │ EIP        │  ← 第二阶段加          │
│   │ 点数机      │ │ 包装机      │                       │
│   └────────────┘ └────────────┘                       │
│                          │                            │
│                          ▼                            │
│                   ┌──────────────┐                    │
│                   │ 英科统一网关   │ (PSM 协议 3.x)     │
│                   │ 推报警 / 登录 │                    │
│                   └──────────────┘                    │
└──────────────────────────────────────────────────────┘
```

**关键点**：
- **新 EdgeHost 完全替代 PSM**（不再依赖海康 PSM）
- **保留视觉软件 → EdgeHost 的对接协议**（跟 PSM 兼容，视觉软件不用改）
- **保留 EdgeHost → 英科系统的协议**（按 PSM 协议 3.x）
- **UI 保留**（Web 端，沿用 PSM 的 UI 设计）
- **新增 OPC UA / EIP** 拉机台数据（点数机 + 包装机）

## 📊 工作分解（按老板"现阶段先复刻 PSM"）

### ★ 第一阶段：复刻 PSM（老板说"现阶段主要工作"）

#### W1-W2：基础 + 数据接收

| 任务 | 输入 | 输出 | DoD |
|---|---|---|---|
| 1.1 项目骨架 | .NET 9 / Java 17 选型 | 可运行的空工程 | `dotnet run` / `java -jar` 能起 |
| 1.2 HTTP Server | - | 监听端口 + REST 框架 | 能响应 `GET /health` |
| 1.3 数据库 | SQLite / PostgreSQL | 22 张 PSM 表 schema | Flyway 迁移 + 表能查 |
| 1.4 接收 `/client/data/detect` | DetectDataUploadDTO | defect_record 入库 | curl 测试通过 |
| 1.5 接收 `/client/data/alarm` | AlarmDTO | alarm_record 入库 | curl 测试通过 |
| 1.6 接收 `/client/data/status` | List\<StatusRecordPO\> | status_record 入库 | curl 测试通过 |

#### W3：字典查询 + 缺陷查询

| 任务 | 输出 |
|---|---|
| 1.7 字典接口 `/client/yk/line-defect` | 查 line + defect_type 返回 |
| 1.8 缺陷查询 `/client/yk/defect-record` | 按条件查 defect_record |
| 1.9 响应格式 | 严格按 PSM 协议 1+2 |

#### W4-W5：英科对接 + 报警推送

| 任务 | 输出 |
|---|---|
| 1.10 英科登录 | 拿 Ticket 缓存 |
| 1.11 报警推送 `/api/dataportal/invoke` | 调英科统一网关 |
| 1.12 Ticket 自动重登（每 50 分钟）| 定时任务 |
| 1.13 推送重试 + 失败队列 | 报警不丢 |

#### W6：UI 大屏

| 任务 | 输出 |
|---|---|
| 1.14 Web UI 框架 | Vue / React 选型 |
| 1.15 大屏展示（产线状态 + 实时缺陷）| 大屏页面 |
| 1.16 日志查询界面 | /web/log |
| 1.17 配置查询界面 | /web/system-config |

#### W7：看门狗 + PG 工具

| 任务 | 输出 |
|---|---|
| 1.18 Windows 服务化（看门狗）| 自动重启 + 开机自启 |
| 1.19 PG 客户端（看门狗的子功能）| 嵌一个 pgAdmin-lite |
