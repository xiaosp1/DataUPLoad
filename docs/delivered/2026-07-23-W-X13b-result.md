## 3. 3 道熔断代码 diff（核心段）

### 3.1 熔断 1（配置门）— line 135-146

```csharp
// ----- 熔断 1（配置门）：yk:enable=false 直接跳过 -----
var ykEnableRaw = _configuration[YkEnableConfigKey];
var ykEnabled = !string.Equals(ykEnableRaw, "false", StringComparison.OrdinalIgnoreCase)
                && !string.Equals(ykEnableRaw, "0", StringComparison.OrdinalIgnoreCase);
// 默认值安全：appsettings 缺失/空时按"禁用"处理（与 W-X13a 写入的默认值一致）。
if (string.IsNullOrEmpty(ykEnableRaw) || !ykEnabled)
{
    _logger.LogInformation(
        "YingkeServiceImpl.HandleOneAsync 熔断[配置门 yk:enable={Raw}] drain-only uuid={Uuid} defect={Defect}",
        ykEnableRaw ?? "<null>", alarm.Uuid, alarm.DefectName);
    return;
}
```

**设计要点**：
- 读 `_configuration["yk:enable"]`（runtime value，非编译期 const → 干掉 CS0162 warning）
- 接受 `"false"` / `"0"` / 空 / null 全部视为关；其它值视为开（容错性高）
- 默认值安全：appsettings 缺失/空 → 关（防意外开）

### 3.2 熔断 2（票据门）— line 148-158

### 3.3 熔断 3（白名单门）— line 160-170 + helper line 224-275

```csharp
// ----- 熔断 3（白名单门）：推送目标 IP 不在白名单则跳过 -----
if (!IsYkTargetIpInWhiteList(out var targetIp, out var rejectReason))
{
    _logger.LogWarning(
        "YingkeServiceImpl.HandleOneAsync 熔断[白名单门 reason={Reason} ip={Ip}] drain-only uuid={Uuid} defect={Defect}",
        rejectReason, targetIp ?? "<unknown>", alarm.Uuid, alarm.DefectName);
    return;
}

// ... helper ...
private bool IsYkTargetIpInWhiteList(out string? targetIp, out string rejectReason)
{
    targetIp = null;
    try
    {
        if (!Uri.TryCreate(_ykOptions.Url, UriKind.Absolute, out var uri) || string.IsNullOrEmpty(uri.Host))
        {
            rejectReason = "ykOptions.Url 解析失败";
            return false;
        }
        targetIp = uri.Host;
    }
    catch
    {
        rejectReason = "ykOptions.Url 异常";
        return false;
    }

    var section = _configuration.GetSection(WhiteListConfigSection);
    if (!section.Exists()) { rejectReason = "白名单配置节缺失"; return false; }

    var whitelist = section.Get<string[]>();
    if (whitelist == null || whitelist.Length == 0) { rejectReason = "白名单为空"; return false; }

    foreach (var entry in whitelist)
    {
        if (string.IsNullOrWhiteSpace(entry)) continue;
        if (string.Equals(entry.Trim(), targetIp, StringComparison.OrdinalIgnoreCase))
        {
            rejectReason = string.Empty;
            return true;
        }
    }

    rejectReason = "目标 IP 不在白名单";
    return false;
}
```

**设计要点**：
- IP 来源：`_ykOptions.Url` 的 host（例：`http://192.168.80.33:10031/...` → `192.168.80.33`）
- 配置节：`IntcoEdge:YingkeGateway:WhiteList`（数组形式，按工单 spec）
- **fail-closed**：配置节缺失 / 数组为空 / IP 不在 → 全部拒绝（防意外开）
- 不支持 CIDR / 通配符（YAGNI；如有需要后续单独工单加）
