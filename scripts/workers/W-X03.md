# W-X03：自查新模块的注入反模式（老板 20:42 派工）

## 背景
W-F01-A Worker 写的 `YKScheduledTicketRenewer` 用 `@Autowired YKServiceImpl` 踩了 JDK 动态代理坑（启动失败）。PM 必须排查其他新模块是否也有同样问题。

## 任务（PM 群里有 12 个新功能 .java，必须都查）

### 扫描命令
```powershell
cd E:\DEMO\数据采集\DataupLoad\src\main\java
# 找所有 @Autowired + 注入 *Impl（具体类，不是接口）
Get-ChildItem -Recurse -Filter "*.java" |
    Where-Object { $_.LastWriteTime -gt (Get-Date).AddHours(-2) } |  # 2 小时内改的（Worker 写的）
    ForEach-Object {
        $content = Get-Content $_.FullName -Raw
        if ($content -match "@Autowired[\s\S]{0,200}Impl\s") {
            [PSCustomObject]@{File = $_.FullName; HasImplInject = $true}
        }
    } | Format-Table -AutoSize
```

### 对每条命中，输出
1. 文件路径
2. 行号
3. 注入的字段名和类型
4. **判断**：注入 `*Impl`（具体类）= 有风险；注入 `*Service`（接口）= 安全
5. 如果有风险：给出修法（改成接口注入 + 加 import，或加 @Lazy）
