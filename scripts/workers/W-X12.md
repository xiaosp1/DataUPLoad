本工单负责监控脚本，要盯 3 个信号：

## 必须做的事

### 1. 写脚本：`scripts/monitor-yk-push.ps1`

脚本功能：
- 探针 1：扫日志 `E:\DEMO\数据采集\logs\dataupload.out.log` 最近 5 分钟，找关键字
  - 异常关键字（应该 0 次）：`pushAlarm2YK called`、`get ticket success`、`attempting yk push`
  - 正常关键字（应该 ≥1 次）：`push alarm to yk error, ticket is null` 或 `yk.enable=false skip push`
- 探针 2：查 PG `alarm_record` 表增长率
  - 当前 5 分钟 INSERT 数
  - vs 上一个 5 分钟 INSERT 数
  - **阈值**：单 5 分钟超过 100 条 → 异常（PSM 同场景约 1-5 条/5 分钟）
- 探针 3：yk.enable 配置校验
  - 读 `DataupLoad/config/application-prod.yml`
  - 验证 `enable: false` 持久化
  - **被改 true 立即告警**

脚本骨架：
```powershell
# scripts/monitor-yk-push.ps1
[CmdletBinding()]
param(
    [int]$IntervalSec = 300,  # 5 分钟
    [string]$LogFile = "E:\DEMO\数据采集\logs\dataupload.out.log",
    [string]$YkConfigFile = "E:\DEMO\数据采集\DataupLoad\config\application-prod.yml",
    [string]$PgConn = "Host=127.0.0.1;Port=5433;Username=postgres;Password=postgres;Database=intco"
)

# === 探针 1: 日志关键字扫描 ===
$tail = Get-Content $LogFile -Tail 5000 -ErrorAction SilentlyContinue
$badKeywords = @('pushAlarm2YK called', 'get ticket success', 'attempting yk push')
$goodKeywords = @('ticket is null', 'yk.enable=false', 'enable=false skip push')

$badHits = @()
foreach ($kw in $badKeywords) {
    $hits = $tail | Select-String -Pattern $kw -SimpleMatch
    if ($hits.Count -gt 0) {
        $badHits += "$kw × $($hits.Count)"
    }
}

# === 探针 2: PG alarm_record 增长率 ===
$pgCount5min = psql ... -c "SELECT COUNT(*) FROM alarm_record WHERE create_time > NOW() - INTERVAL '5 minutes';"
$pgCountPrev5min = psql ... -c "SELECT COUNT(*) FROM alarm_record WHERE create_time BETWEEN NOW() - INTERVAL '10 minutes' AND NOW() - INTERVAL '5 minutes';"

# === 探针 3: yk.enable 校验 ===
$ykEnableLine = Get-Content $YkConfigFile | Select-String -Pattern 'enable:' | Select-Object -First 1
$ykEnableValue = if ($ykEnableLine -match 'enable:\s*true') { 'true' } else { 'false' }

# === 报告 ===
$ts = Get-Date -Format "yyyy-MM-dd HH:mm:ss"
$report = @"
[$ts] 灰盒监控报告
- 探针 1 (yk 调用): $($badHits.Count -gt 0 ? "🔴 异常: $($badHits -join ', ')" : "✅ 0 异常")
- 探针 2 (PG 增长): 5min 新增=$pgCount5min, 上 5min=$pgCountPrev5min $(if($pgCount5min -gt 100){'🔴 超阈'} else {'✅'})
- 探针 3 (enable): $ykEnableValue $(if($ykEnableValue -eq 'true'){'🔴'} else {'✅'})
"@

Write-Host $report

# 异常时写告警文件
if ($badHits.Count -gt 0 -or $pgCount5min -gt 100 -or $ykEnableValue -eq 'true') {
    $alertFile = "E:\DEMO\数据采集\logs\yk-monitor-alert-$(Get-Date -Format 'yyyyMMdd_HHmmss').log"
    $report | Out-File $alertFile -Encoding utf8
}
```

- cron job 注册失败 → 群里报，手工跑
