# W-X16：灰盒验证 2 - ignore 过滤真生效

**优先级**：P0（灰盒跑法第 2 关：验证 PSM ignore_alarm 表 + Controller 端到端生效）
**金标准**：PSM 反编译 `IgnoreAlarmServiceImpl` + `AlarmRecordServiceImpl.handleAlarmIgnore`
**依赖**：W-X11（必须先部署 V1.20 SQL 让 ignore_alarm 表存在）
**预计**：20 分钟

---

## 背景

PSM `ignore_alarm` 表是"黑名单"机制：把某 `(defectName + lineNo + faceNo + workshop)` 标 ignore 后，**同组合的报警不会被算 UNSOLVED，不会触发 yk 推送**。
W-F02-A/B/C 在 hik-java 端补齐了：
- `IgnoreAlarm` PO + Mapper + Service + Impl（4 个 .class）
- `IgnoreAlarmController` HTTP 接口
- V1.20__ignore_alarm.sql 表结构

但**没端到端测过**：插一行 ignore → 推同组合报警 → 看是否被忽略。

## 必须做的事（5 步法）

### Step 1：基线快照
- 查 ignore_alarm 表当前行数：
  ```sql
  SELECT COUNT(*) FROM ignore_alarm;
  ```
- 查 alarm_record 当前总数：
  ```sql
  SELECT COUNT(*) FROM alarm_record;
  ```
- 记到报告

### Step 2：插 1 行 ignore（直接 SQL）
- 用 PSM `IgnoreAlarm` PO 同款字段：
  ```sql
  INSERT INTO ignore_alarm (defect_name, line_no, face_no, workshop, expire_time, create_time, update_time)
  VALUES ('测试缺陷_ignore过滤验证', 'TEST_LINE_X16', 'TEST_FACE_X16', 'QZN2',
          NOW() + INTERVAL '7 days', NOW(), NOW());
  ```
- 复查：
  ```sql
  SELECT * FROM ignore_alarm WHERE line_no = 'TEST_LINE_X16';
  ```
  → 必须返回 1 行

### Step 3：推报警（用同组合 defectName+lineNo+faceNo）
- POST `http://127.0.0.1/client/data/alarm`：
  ```json
  {
    "lineNo": "TEST_LINE_X16",
    "faceNo": "TEST_FACE_X16",
    "defectName": "测试缺陷_ignore过滤验证",
    "type": "DEFECT",
    "count": 1,
    "level": "警告",
    "message": "W-X16 ignore 过滤测试"
  }
  ```
- **关键**：这个组合正好在 ignore_alarm 表里

### Step 4：等 5 秒 + 查 PG 验证被忽略
- 等 5 秒
- 查 alarm_record：
  ```sql
  SELECT uuid, line_no, face_no, defect_name, solve, send_status, yk_code
  FROM alarm_record
  WHERE line_no = 'TEST_LINE_X16';
  ```
- **期望结果**：
  - **报警根本没入库**（alarm_record 0 行）—— PSM 是先查 ignore_alarm，匹配到直接 return
  - 或者：入库了但 solve=3 (IGNORE)，不触发 SendAlarmMessage
  - yk 日志：无 pushAlarm2YK called
- **关键验证**：yk 推送 0 条

### Step 5：清理测试数据（必须）
- 删：
  ```sql
  DELETE FROM ignore_alarm WHERE line_no = 'TEST_LINE_X16';
  DELETE FROM alarm_record WHERE line_no = 'TEST_LINE_X16';
  ```
- 复查：
  ```sql
  SELECT COUNT(*) FROM ignore_alarm; -- 回到基线
  SELECT COUNT(*) FROM alarm_record; -- 回到基线
  ```

## DoD

| 项 | 标准 |
|---|---|
| ignore_alarm 表存在 | Step 1 查到 COUNT |
| 插 1 行 ignore 成功 | Step 2 复查 1 行 |
| 推同组合报警 | Step 3 推 1 条 |
| alarm_record 不增 | Step 4 查不到 / 查到 0 UNSOLVED |
| yk 推送 | 0 条（日志无 pushAlarm2YK called）|
| 测试数据清理 | Step 5 回到基线 |

- yk 推送 >0 → 立刻群里报
