# W-F04：客户端掉线自动报警

## 范围（最多 2 个文件）
1. 新增 `E:\DEMO\数据采集\DataupLoad\src\main\java\com\hikrobotics\solution\module\alarm\service\ClientOnlineChecker.java`

## 任务
客户端（工控机）WS 断开 5 秒后，自动生成 type=3 报警。

## 依据
PSM 反编译 `AlarmRecordServiceImpl.dealClientAlarmListener` 字节码：
- `dealClientAlarm(String lineNo, String faceNo, Integer type)`：处理客户端掉线
- 调 `eventPublisher.publishEvent(new DealAlarmEvent(...))`

## 实现要点
1. `@Component` 类 `ClientOnlineChecker`
2. 用 `ScheduledExecutorService` 每 5 秒检查一次 WS 在线列表（找 framework-starter 的 `WebSocketHandler`）
3. 如果某 clientNo 上次在线、这次不在 → 调 `alarmRecordService.dealClientAlarm(lineNo, faceNo, type=3)`
4. log WARN："client offline detected.[line={}][face={}][clientNo={}]"

由于 framework-starter 的 WebSocketHandler 实际 API 不确定，本任务可以**只写 stub + TODO**，标 "需要 PM 确认 WebSocketHandler API"

## 验证

- 跑通启动逻辑（即使 WS 检测是 stub）

## 约束

- **不准重启服务**
- **不准推测试报警**
- stub 也行，必须编译通过
