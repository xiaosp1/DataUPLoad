## 任务

```

180-201: alarmDTO.setAlarmCount(int), setAlarmDetails("..." + count)
```

## 实现要点
在 `pushAlarm2YK` 已有方法中（不要新建方法），在调 `HikWebClient.create()` 推 yk **之前**加：

```java
// === PSM 防爆 #1：报警聚合（PM 2026-07-22 18:35 W-F03）===
AlarmRecordPO record = event.getAlarmRecord();
if (StringUtils.isNotBlank(record.getDefectName())) {
    long count = alarmRecordDAO.selectCount(Wrappers.<AlarmRecordPO>lambdaQuery()
            .eq(AlarmRecordPO::getDefectName, record.getDefectName())
            .eq(AlarmRecordPO::getLineNo, record.getLineNo())
            .eq(AlarmRecordPO::getFaceNo, record.getFaceNo())
            .eq(AlarmRecordPO::getType, record.getType())
            .eq(AlarmRecordPO::getSolve, AlarmSolvedEnum.UNSOLVED.getValue()));
    alarmDTO.setAlarmCount((int) count);
    alarmDTO.setAlarmDetails(alarmDTO.getAlarmDetails() + "，已发生 " + count + " 次");
}
```

注意：
- `alarmRecordDAO` 已经在 YKServiceImpl 里有字段（之前反编译看到）
- `AlarmSolvedEnum` 在 `com.hikrobotics.solution.module.alarm.constant`
- `Wrappers` 是 `com.baomidou.mybatisplus.core.toolkit.Wrappers`
