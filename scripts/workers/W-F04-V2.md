## 任务
客户端 WS 断开 30 秒后，自动生成 type=3 报警落 PG（**不直接推 yk**，统一走 add() 入口）。

## 依据
PSM 反编译 `AlarmRecordServiceImpl.dealClientAlarmListener` 字节码：
- `dealClientAlarm(String lineNo, String faceNo, Integer type)`：处理客户端掉线
- PSM 是生成报警后通过 add() 入口推 yk

## 实现要点
1. `@Component` 类 `ClientOnlineChecker`
2. 用 `ConcurrentHashMap<String, Long>` 存 `clientNo → lastHeartbeatMs`
3. `@Scheduled(fixedDelay = 30 * 1000)` 每 30 秒扫描，超时（> 60 秒无心跳）触发报警
4. 报警内容：
   ```java
   AlarmDTO dto = new AlarmDTO();
   dto.setUuid(UUID.randomUUID().toString());
   dto.setTime(new Date());
   dto.setType(3); // 设备
   dto.setLineNo(lineNo);
   dto.setFaceNo(faceNo);
   dto.setLevel(2); // 严重
   dto.setMessage("客户端掉线[" + clientNo + "]");
   alarmRecordService.add(dto);
   ```
5. **⚠️ 关键约束**：yk.enable=false 当前，调用 alarmRecordService.add() 不会推 yk，只落 PG（满足老板 SOP）
