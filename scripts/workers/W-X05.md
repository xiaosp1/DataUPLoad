# hik-java 回滚 SOP

## 适用场景
- 新版本 target/classes 启动失败
- 新功能踩坑导致 Spring Boot 启动失败
- 老板下令回滚

- 老 hik-java PID 已知（看 STATUS.md 历史）

## 回滚 3 步（1 分钟搞定）

### Step 1：杀当前失败的进程
```powershell
Get-Process -Name "hik-java" -ErrorAction SilentlyContinue | Stop-Process -Force
```

### Step 2：还原 target/classes
```powershell
# 用最近一次能跑的备份
$latest = Get-ChildItem "E:\DEMO\数据采集\DataupLoad\target\classes-backup-*" -Directory | Sort-Object LastWriteTime -Descending | Select-Object -First 1
Remove-Item "E:\DEMO\数据采集\DataupLoad\target\classes" -Recurse -Force
Copy-Item $latest.FullName "E:\DEMO\数据采集\DataupLoad\target\classes" -Recurse -Force
```

### Step 3：起老 hik-java
```powershell
cmd /c "start /B E:\DEMO\数据采集\DataupLoad\scripts\start-app.bat"
Start-Sleep 60
Get-NetTCPConnection -State Listen -LocalPort 80  # 必须有 LISTEN
```

## 备份策略
- 每次 PM 重启 hik-java 前，必须先备份 classes/
- 备份命名：`classes-backup-yyyyMMdd-HHmmss`
- PM 在 STATUS.md 记最新可用备份路径

## 回滚失败怎么办

- PM 群里汇报
- 老板拍下一步

## 关联

- W-X04 集成测试

```
