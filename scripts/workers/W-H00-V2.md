## 实现要点
脚本内容：
```powershell
# heartbeat-to-feishu.ps1
# 每 10 分钟生成心跳报告（PM 在群里转发）

$outFile = "E:\DEMO\数据采集\heartbeat-current.txt"
$port = (Get-NetTCPConnection -State Listen -LocalPort 80 -ErrorAction SilentlyContinue).OwningProcess
$proc = if ($port) { Get-Process -Id $port -ErrorAction SilentlyContinue | Select-Object Id, ProcessName, @{N='Mem(MB)';E={[Math]::Round($_.WorkingSet64/1MB,0)}}, StartTime | Format-Table | Out-String } else { "❌ DOWN" }

$ykStatus = if (Select-String -Path 'E:\DEMO\数据采集\DataupLoad\config\application-prod.yml' -Pattern 'enable: true' -Quiet) { "⚠️ ON" } else { "✅ OFF（已熔断）" }

$workerCount = (Get-Process -Name "codex*" -ErrorAction SilentlyContinue | Measure-Object).Count

$msg = @"
🏭 PM 心跳（$(Get-Date -Format 'yyyy-MM-dd HH:mm:ss')）
- hik-java 80 端口：$proc
- yk 推送：$ykStatus
- Worker 进程：$workerCount 个
- PG 5433：$((Get-NetTCPConnection -State Listen -LocalPort 5433 -ErrorAction SilentlyContinue).OwningProcess) 进程
- 最近 5 条 alarm log：
$(Get-Content 'E:\DEMO\数据采集\DataupLoad\log\DataupLoad\info.log' -Tail 5 -ErrorAction SilentlyContinue | Select-String -Pattern 'alarm|Alarm|YK' | Select-Object -First 5)
"@

$msg | Out-File -FilePath $outFile -Encoding UTF8
Write-Host "心跳写入: $outFile"
Write-Host $msg
```
